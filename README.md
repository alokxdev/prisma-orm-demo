# Prisma Sandbox

This repository contains a simple playground for experimenting with [Prisma](https://www.prisma.io) ORM. It's a personal learning project used to try out schema design, migrations, and basic CRUD logic.

## Structure

- `schema.prisma` – defining the data models for `User` and `Todo`.
- `migrations/` – files generated by Prisma CLI when running `prisma migrate`.
- `src/index.ts` – minimal TypeScript script that initializes the Prisma Client and demonstrates basic create/update operations.
- `package.json`, `tsconfig.json` – standard Node/TypeScript configuration.
- `.env` – environment variables (ignored in Git) for the database connection.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Configure your database URL in `.env`, e.g.:
   ```
   DATABASE_URL="postgresql://user:pass@localhost:5432/mydb?schema=public"
   ```
3. Run migrations to create tables:
   ```bash
   npx prisma migrate dev --name init
   ```
4. Generate Prisma client if needed:
   ```bash
   npx prisma generate
   ```

## Usage

Modify `src/index.ts` to experiment with queries. Example logic is already present to create users and todos.

Run the script with:

```bash
npx tsc -b  # compiles TypeScript to dist/
node .dist/index.js
```

## Notes

- This is purely for learning; no extensive error handling or environment management included.
- Generated files and credentials are ignored via `.gitignore`.
- Feel free to delete/recreate schema models and run migrations as you experiment.
